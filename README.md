# MaterialYouKit

Твик для джейлбрейка iOS 15+: Material You на системном уровне.

Что умеет (v1.0):
- акцентный цвет во всех приложениях (кнопки, ссылки, ползунки)
- переключатели в стиле Material
- док «таблеткой» с тональной подложкой
- 8 цветов на выбор, всё включается и выключается в Настройках -> Material You

## Сборка через GitHub Actions
1. Создай репозиторий на GitHub и загрузи туда все файлы (структуру папок сохрани).
2. Открой вкладку **Actions** -> **Build tweak** -> **Run workflow**.
3. Когда сборка закончится, скачай артефакт **MaterialYouKit-deb**: внутри два .deb
   (`iphoneos-arm` для rootful и `iphoneos-arm64` для rootless).
4. Установи нужный .deb через Filza или добавь в свою репу для Sileo/Zebra.

Если сборка упала, скопируй лог красного шага и пришли его, поправим.
